# Application icon provenance

The V1 icon is an original project asset generated with OpenAI ImageGen and then processed locally into transparent PNG and multi-resolution ICO files.

Prompt summary: a centered open book with warm cream pages, charcoal outlines, and a small amber bookmark; calm Kindle-style flat vector treatment; no text, letters, gradients, trademarks, device mockups, or shadows; solid green chroma background for deterministic alpha removal.

- Generated source: retained outside the repository in the local Codex generated-image cache.
- Processed master: `packaging/assets/icon.png`
- Windows icon: `packaging/assets/icon.ico` (16, 20, 24, 32, 40, 48, 64, 128, and 256 px frames)
- Processing script: `packaging/build-icon.py`
